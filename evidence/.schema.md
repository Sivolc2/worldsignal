# Evidence Store Schema

Each piece of evidence is a JSON file in `evidence/items/` with this structure:

```json
{
  "id": "uuid",
  "timestamp": "ISO-8601",
  "source": "arxiv | github | alphasignal | dwarkesh | moonshot | other",
  "title": "string",
  "url": "string",
  "summary": "1-3 sentences, agent-generated",
  "relevance": "why this matters to the steward's context",
  "tags": ["string"],
  "cluster": "string (assigned by clustering, null initially)",
  "embedding": "stored in vector DB, not in JSON",
  "hypotheses": ["H1", "H3"],
  "direction": "supports | challenges | neutral",
  "shared": false,
  "steward_reaction": null
}
```

## Directories

- `evidence/items/` — individual evidence JSON files
- `evidence/clusters/` — cluster definitions and membership

## Rules (from governance contract)

- Append-only: never delete evidence, only reclassify
- No hallucinated sources: every item must have a real URL
- No engagement-optimized selection: filter for importance, not provocation
